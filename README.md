# Теплорасчет: Передача тепла от газа к трубе

Программа для инженерного расчета теплопередачи от потока горячего газа (дымовые газы, воздух) к стенке трубы. Учитывает конвективную и лучистую составляющие теплообмена.

## Возможности

- Расчет теплового потока (Q, Вт) от газа к трубе
- Учет конвективного и лучистого теплообмена (излучение включается для T > 300°C)
- Поддержка различных типов газа: дымовые газы, воздух, азот, пропан, пользовательский
- Выбор материалов трубы: сталь 20, нержавейка, медь, чугун, пользовательский
- Различные условия обтекания: поперечное (одиночная труба/пучок), продольное
- **Два режима работы:**
  - **Консольный режим** (задание параметров в коде)
  - **Графический интерфейс (GUI)** для удобного ввода параметров

## Технологии

- Python 3.7+
- Tkinter (графический интерфейс, входит в стандартную библиотеку Python)
- Dataclasses (для строгой типизации данных)

## Установка и запуск

### 1. Убедитесь, что установлен Python

Проверьте версию Python:
```bash
python --version

Требуется Python 3.7 или новее.
2. Скачайте или скопируйте файлы проекта

Создайте папку теплорасчет и поместите в неё файлы:
text

теплорасчет/

├── calculate.py      # Модуль расчета
├── gui.py            # Графический интерфейс

└── README.md         # Этот файл

3. Запуск программы
Графический интерфейс (рекомендуется)
bash

python run_gui.py

Консольный режим (для отладки или автоматизации)
bash

python calculate.py   # использует параметры из main.py

Примечание: Если возникает ошибка кодировки (UnicodeEncodeError), замените в файлах эмодзи на обычный текст или запустите в современном терминале (Windows Terminal, PowerShell 7+).
Как пользоваться GUI

После запуска run_gui.py откроется окно с четырьмя вкладками:
1. Вкладка "Газ"

    Тип газа: выберите из списка. Если выбран "пользовательский", нужно заполнить поля теплопроводности, вязкости и числа Прандтля.

    Температура газа (°C): например, 800

    Скорость газа (м/с): например, 5

    Содержит H2O/CO2: включите для учета излучения (для дымовых газов обязательно)

2. Вкладка "Труба"

    Наружный диаметр (мм): 57

    Внутренний диаметр (мм): 50

    Длина трубы (м): 1.0

    Материал трубы: выберите из списка или "пользовательский"

    Теплопроводность стенки (Вт/(м·К)): для стали 20 это 51.5

3. Вкладка "Омывание"

    Тип обтекания: поперечное (одиночная труба или пучок) / продольное

    Для пучка труб дополнительно укажите расположение и количество рядов

4. Вкладка "Границы"

    Выберите способ задания условий: температура внутренней стенки ИЛИ среда внутри трубы

    Учёт излучения: включите для газов с температурой выше 300°C (рекомендуется)

Запуск расчета

Нажмите кнопку "ВЫПОЛНИТЬ РАСЧЁТ". Результат появится на вкладке "Результат". Там же можно сохранить отчёт в файл result.txt.

Исходные данные:

    Газ: дымовые газы, 800°C, 5 м/с

    Труба: сталь 20, Dнар=57 мм, Dвн=50 мм, L=1 м

    Условия: поперечное омывание одиночной трубы

Структура файлов
Файл	Назначение
main.py	Определяет классы данных (GasParams, PipeGeometry, HeatTransferInput и др.) с типизацией.
calculate.py	Содержит функции расчёта: calculate_alpha_convection_gas, calculate_alpha_radiation, calculate_overall_coefficient, calculate_heat_flow.
gui.py	Реализует графический интерфейс на Tkinter.
run_gui.py	Точка входа для запуска GUI.
Алгоритм расчета

    Расчёт конвективного коэффициента теплоотдачи (α_конв)

        Определение числа Рейнольдса (Re)

        Выбор критериального уравнения в зависимости от типа обтекания

        Расчёт числа Нуссельта (Nu)

        Вычисление α_конв = Nu·λ / d

    Расчёт лучистого коэффициента (α_изл) — если включён

        По закону Стефана-Больцмана с учётом степеней черноты газа и стенки

    Расчёт линейного коэффициента теплопередачи (K_л)

        Учитываются термические сопротивления: внутреннее, стенки трубы, наружное

        Формула для цилиндрической стенки

    Расчёт теплового потока

        q_л = K_л·π·ΔT

        Q = q_л·L

Известные ограничения

    Теплофизические свойства газов аппроксимированы упрощёнными формулами (для инженерных оценок точность достаточна)

    Не учитывается теплопроводность отложений (накипи) на стенках трубы

    Для пучков труб используются усреднённые коэффициенты (более точный расчёт требует CFD)

Расширение функциональности

При необходимости вы можете:

    Добавить новые типы газов в calculate.py (дополнить блок if gas.gas_type == ...)

    Ввести расчёт многослойной изоляции (добавить термические сопротивления в calculate_overall_coefficient)

    Подключить чтение параметров из Excel или CSV
