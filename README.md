# Универсальный калькулятор теплопередачи

Многофункциональное приложение для расчёта тепловых потоков в различных сценариях теплообмена: конвекция, излучение, теплопередача через стенку, а также комбинированные задачи (газ-труба). Программа предоставляет как графический интерфейс (Tkinter), так и возможность программного вызова расчётных функций.

---

## 📋 Возможности

- **Четыре типа задач**:
  1. **Газ-труба** – теплоотдача от горячего газа к наружной поверхности трубы с учётом конвекции и излучения.
  2. **Излучение между поверхностями** – теплообмен излучением между двумя серыми телами (с заданными степенями черноты и коэффициентом облучения).
  3. **Теплопередача через плоскую стенку** – стационарная теплопередача от горячей жидкости к холодной через многослойную стенку (с учётом конвекции с обеих сторон).
  4. **Конвективный теплообмен** – расчёт коэффициента теплоотдачи и теплового потока при вынужденной или свободной конвекции для различных геометрий (плоская пластина, труба, сфера).

- **Графический интерфейс** на Tkinter с вкладками для каждого типа задачи, удобным вводом данных и отображением результатов.

- **Модульная архитектура** – ядро расчётов отделено от GUI, что позволяет использовать его в скриптах или интегрировать в другие проекты.

- **Юнит-тесты** – покрытие ключевых расчётных функций и обработка пограничных случаев (нулевые температуры, отсутствие параметров, деление на ноль).

- **Сохранение результатов** – возможность сохранить отчёт в текстовый файл `result.txt`.

## 🚀 Установка и запуск

### Требования
- Python 3.6 или выше
- Стандартная библиотека (Tkinter, unittest, dataclasses, math) – дополнительных пакетов не требуется.


### 🔧 Исполняемый файл (.EXE)

**Исполняем файл находиться в папке dist(может независимо работать от исходного кода)**

### Клонирование репозитория

git clone https://github.com/your-username/heat-transfer-calculator.git
cd heat-transfer-calculator

# Запуск Юнит-тестов
python -m unittest test_calculate.py
# Запуск графической оболочки программы
python run_gui.py

📂 Структура проекта

heat-transfer-calculator/

🧮 Использование
Графический интерфейс

    Запустите run_gui.py или собранный .exe.

    Выберите вкладку с нужным типом задачи:

        Газ-труба – заполните параметры газа, трубы, условия омывания, граничные условия.

        Излучение – укажите температуры, степени черноты, коэффициент облучения и площадь.

        Стенка – введите температуры жидкостей, коэффициенты теплоотдачи, размеры стенки.

        Конвекция – задайте тип жидкости, температуры, скорость, характерный размер и геометрию.

    Нажмите кнопку «ВЫПОЛНИТЬ РАСЧЁТ».

    Результат отобразится на вкладке «Результат».

    Нажмите «Сохранить результат в файл» для экспорта отчёта в result.txt.


🧪 Тестирование

Юнит-тесты охватывают:

    Проверку положительности результатов.

    Пограничные случаи (равные температуры, нулевые коэффициенты, отсутствие параметров).

    Корректную обработку ошибок (деление на ноль, отсутствие обязательных полей).

    Все четыре типа задач, а также пользовательские свойства и значения по умолчанию.

Чтобы запустить тесты с подробным выводом:
python -m unittest -v test_calculate.py

 📖 Расширение и модификация
Добавление нового типа задачи

    В main.py:

        Добавьте новый литерал в CaseType.

        Определите новый dataclass для входных параметров.

        Добавьте соответствующее поле в HeatTransferInput.

    В calculate.py:

        Напишите функцию расчёта для нового типа.

        Добавьте ветвление в calculate_heat_flow.

    В gui.py:

        Создайте новую вкладку с полями ввода.

        Добавьте метод _get_<new>_data() для сбора данных.

        Обновите get_input_data() для распознавания новой вкладки.

    В test_calculate.py:

        Добавьте тесты для новой функции.

Изменение физических моделей

Все корреляции (числа Нуссельта, формулы для излучения и т.д.) находятся в calculate.py. Вы можете заменить их на более точные или адаптировать под свои задачи.
